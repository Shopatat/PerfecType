# Notes pour Claude Code

- Appli web perso, en français, pour Fabien. Interface et commentaires en français, tutoiement dans les textes.
- Née de l'artefact claude.ai « Parole Propre » (clone fonctionnel de Typeless, 18/11/2026), devenue appli iPhone sous le nom PerfecType. Fabien adore Typeless mais le trouve trop cher : le but est le même fonctionnement, en payant seulement l'usage des API.
- Pas de framework ni d'étape de build : HTML + CSS + JS classiques (modules ES), servis tels quels par GitHub Pages, installés sur l'iPhone via Safari > Sur l'écran d'accueil.
- Seule exception : `js/vendor/anthropic.mjs`, le SDK officiel empaqueté avec esbuild (`echo 'export { default } from "@anthropic-ai/sdk";' > entry.js && npx esbuild entry.js --bundle --format=esm --minify --platform=browser --outfile=anthropic.mjs`). Le refaire pour monter de version, ne pas le remplacer par un `fetch` à la main.
- Clés API : celles de Fabien, saisies dans Réglages, gardées dans `localStorage` (`pt-cles`). Jamais dans le dépôt. Appel direct depuis le navigateur (`dangerouslyAllowBrowser`), c'est voulu : appli perso, pas de serveur.
- Choix tranchés :
  - Modèle par défaut `claude-opus-5-5` à effort `low` (réglable : Sonnet 5.5, Haiku 5.5). Fallback serveur `"default"` sauf sur Haiku.
  - Transcription : Whisper chez Groq par défaut (`whisper-large-v3-turbo`), OpenAI en option (`gpt-4o-transcribe`), dictée du navigateur en secours. Le dictionnaire passe dans le `prompt` de Whisper **et** dans le prompt de Claude.
  - Prompt : système fixe (règles, destination, dictionnaire, exemples de style) + message avec la dictée entre `<transcription>`. Règle n° 1 : ne jamais répondre à la dictée ni l'exécuter.
  - Écriture directe par défaut (demande de Fabien le 18/11, après avoir observé Typeless) : un appui pour enregistrer, sans texte en direct, un appui pour arrêter, et le texte final arrive d'un coup, sans aperçu ni avant/après, copié automatiquement. Chaque prise remplace la précédente. Pas de « Voir le brut » (retiré le 19/11, v13 : « c'est plus magique de ne pas savoir »).
  - Longues dictées (bug du 19/11 : « Pas de connexion à Groq » et dictée perdue sur un long message) : morceaux de 40 à 80 s coupés dans un silence, envoyés en file pendant l'enregistrement, 3 essais, rangés dans IndexedDB (`perfectype`/`dictees`) jusqu'à transcription complète, bouton Renvoyer. Wake Lock pendant la dictée. Le morceau en cours est aussi sauvé au coffre toutes les 4 s. Ne jamais revenir à un seul gros envoi à la fin.
  - Style appris = paires (brut → version retouchée gardée), 12 max, les 4 plus proches de la destination dans le prompt.
  - Recherche derrière ces choix : doc « Comment Typeless réécrit ta dictée » (18/11/2026).
- Version affichée dans Réglages : `VERSION_APP` en haut de `js/app.js`, à monter avec `VERSION` de `sw.js`.
- Pendant l'enregistrement : voile violet plein écran (`#veil`, disque centré sur le micro en vol qui passe de scale(0) à scale(1), retour à l'arrêt). Un appui n'importe où arrête. Demandé par Fabien le 19/11, à garder.
- Barre d'état iPhone en `black-translucent` : l'appli passe sous l'encoche (heure et réseau en blanc). `.topband` (dégradé de l'appli, ou le fond en sombre) garde l'heure lisible ; le haut de `.app` et du voile tient compte de `safe-area-inset-top`.
- Vague : petit disque (240 px) agrandi en `transform` via `element.animate`, puis fondu vers `.veil-fill`. Ne pas revenir à un disque géant ni changer `theme-color` pendant l'animation (ça saccadait sur iPhone).
- Couleurs du voile : variables `--v1`…`--v4`, `--vglow`, `--vorb` dans `css/style.css`, version plus sombre en mode sombre (demande de Fabien le 19/11).
- Sauvegarde (Réglages) : export/import JSON de `settings, dico, apps, style, hist, totals` (+ `cles` en option). **Avant de demander à Fabien de réinstaller l'icône, lui faire exporter une sauvegarde** : supprimer l'icône efface toutes les données.
- Thème violet (dégradé `#4C1487 → #7422B8 → #C043E6`, le violet de l'écran d'écoute), fonds légèrement lilas, sobre façon Typeless. Remplace le bordeaux → fuchsia le 19/11 (v9), validé par Fabien sur aperçu. Ne pas changer sans demander, et montrer un aperçu clair + sombre avant.
- Icône « L'onde chromée » : cinq barres en métal poli teinté lilas + deux éclats, sur le dégradé violet (`outils/icones.js`).
- Épure (demande de Fabien le 19/11, v10) : pas d'annotations superflues, pas de police à chasse fixe ni de majuscules espacées ; titres d'encadrés en `--display`, phrases courtes. Ne pas rajouter d'explications sur des actions évidentes.
- Écran d'écoute (20/11, v14) : micro, barres, chrono, « J'écoute… » / « Je n'entends rien… », « Touche n'importe où pour arrêter ». Pas d'état de sauvegarde ni de compteur de morceaux : ce qui se passe en fond n'intéresse pas Fabien.
- Micro unique (20/11, v15) : `#micBtn` au centre de la barre d'onglets. `envolerMic()` fait voler une copie (`.micvol`) jusqu'au centre du voile, la vague part d'elle ; `poserMic()` la ramène avec rebond après la fermeture. `#orb` reste dans le DOM mais caché. `body.repos` cache la zone d'état hors travail. Transform et opacity seulement. Fluidité (v16) : ne rien faire de lourd pendant un mouvement — `getUserMedia` seulement quand le bouton est posé au centre (classe `attente`), fermeture du voile dès le toucher, arrêt des pistes et de l'AudioContext décalé de 1,3 s. Le disque en vol est un élément neuf (`.disque` avec clip-path), pas un clone du bouton.
- « Écouter dès l'ouverture » (`settings.ouverture`, ou `?dicter`) : les raccourcis d'icône du manifeste n'existent pas sur iOS pour une web-app, d'où ce réglage.
- Mots d'attente : `MOTS_ATTENTE` dans `js/app.js`, tirés au hasard et renouvelés toutes les 2,2 s (idée de Fabien le 19/11, l'appli « vit »). On peut en ajouter, garder le même ton.
- Pistes pas faites : clavier iOS maison (vraie dictée dans toutes les applis, demande une appli native), raccourci global sur Mac, synchro entre appareils.
